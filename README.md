# krmaazha — AI Resume Tailoring

Marketing site for the Resume Sending Agent System. Built as a GitHub Pages single-page site.

## What It Sells

A 5-agent AI pipeline that tailors resumes and outreach messages for specific job posts:

1. **Post Analyzer** — extracts role requirements, company stage, tech stack, tone
2. **Psychology Profiler** — profiles the hiring manager's communication style
3. **Profile Matcher** — maps candidate skills vs requirements, pulls ATS keywords
4. **Resume Writer** — generates a human-sounding resume with zero AI clichés
5. **Message Composer** — writes a brief, personalized outreach message
